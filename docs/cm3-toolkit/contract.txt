Collect without fixture is bounded allowlisted inspection, not an automatic
hardware run in this phase. Bench without --execute returns a plan and starts
NO workloads/probes. Idle execution needs --execute; CPU/memory need both
--execute --allow-load; storage flags are fixture-only; live storage is disabled;
network additionally --allow-network --peer. Boot-SSH requires separate external
observer event input, never reboots or initiates power control. Execution flag
is not authority: conditions must cite separately approved test scope. Fixture
mode never reads live target sources or contacts a peer; it cannot suppress
synthetic marking even with execution flags. Report is offline only.

Output: one JSON object to stdout by default, no implicit saved files. Explicit
--output creates a NEW regular file only in a caller-selected existing directory;
reject existing paths, symlinks, unsafe ancestors and special files; no clobber.
Human diagnostics to stderr. Exit 0 for valid inspection/plans or complete results,
2 for malformed input/authorization rejection, 3 for unavailable measurements,
4 for execution/parser error/timeout. Partial/unavailable fields are still emitted
in JSON; any required unavailable result yields exit 3, errors yield 4. A plan is
not a measurement. Reporting must retain incomplete/error inputs, not hide them.

credentials or personal absolute paths. Raw references use relative artifact
paths, lengths and SHA256; report rejects path escapes and oversized inputs.

BOUNDS AND SAFETY
No automatic installs, sudo, shell=True, service stopping or configuration writes.
Idle default 5 s, hard cap 60 s; other short procedures default 10 s, cap 60 s.
Optional sustained CPU mode must be a distinct explicit protocol with duration
<=3600 s and separate approved scope; short runs cannot claim G6 qualification.
8-hour soak is a separately approved operator protocol, not default execution.
Single command deadline <= procedure duration + 5 s cleanup grace. Kill/reap
entire new process group on timeout, interrupt or error, capture bounded output
(max 1 MiB per stream), close files and remove only owned temporary files.
No uncapped retries/workers; CPU workers <= online CPU count and explicit cap.
Memory <= min(requested, 256 MiB, 25% MemAvailable); preserve >=25% total RAM
or larger reviewed reserve. Invalid/absent capacity data blocks load execution.
Storage <=64 MiB per invocation AND >=25% filesystem capacity free afterwards;
reject insufficient or unmeasurable space before creation. Bound cumulative bytes
written and prohibit time-based rewrites beyond that budget. Approved existing
directory resolved/validated without symlink traversal; new O_EXCL/O_NOFOLLOW
regular owned file, directory-fd relative operations, no raw device/existing file,
no /dev, /proc, /sys or path escape. Recheck identity for cleanup; never unlink an
unrelated replacement. Network probes have finite explicit peer/time/byte bounds;
no scanning, public auto-target, background server or guessed credentials.
Thermal loads require validated sensors, approved thermal abort ceiling/observer,
stop on sensor/control loss or ceiling, never change trip/governor/zram controls.
Missing tool/sensor is unavailable and blocks its dependent procedure, not fallback
to an unreviewed workload. Fixtures simulate effects only in isolated directories.
